# Mão de Vaca 
Sistema de controle financeiro pessoal. Registre receitas e despesas, organize por categoria e acompanhe seu saldo mensal.

## Stack

| |                     |
|---|---------------------|
| Linguagem | Java 26             |
| Arquitetura | MVC + Service Layer |
| Servidor HTTP | HttpServer nativo   |
| Banco de Dados | H2 (arquivo local)  |
| JSON | Jackson             |
| Testes | JUnit 5             |
| Build | Maven               |
